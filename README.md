# Python Dice Adventure

Dieses Repository ist ein kleines Python-Konsolenspiel, das ich Schritt für Schritt aufbaue.

Das Ziel ist, Python-Grundlagen praktisch zu üben und dabei ein kleines Spiel mit Klassen, Würfeln, Lebenspunkten und einfacher Kampflogik zu entwickeln.

---

## Ziel des Projekts

Mit diesem Projekt übe ich:

- Python-Grundlagen
- Klassen und Objekte
- Methoden
- Funktionen
- Module und Imports
- einfache Spiellogik
- Git und GitHub Workflow
- saubere Projektstruktur

---

## Aktueller Stand

Der aktuelle Stand ist eine erste Grundstruktur für das Spiel.

Bereits umgesetzt:

- `Player` Klasse
- `Enemy` Klasse
- Lebenspunkte
- Angriffswerte
- `is_alive()` Methode
- `take_damage()` Methode
- Würfelfunktion mit Zufallszahl von 1 bis 6
- erste Tests in `main.py`
